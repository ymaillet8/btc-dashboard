How the automation works
GitHub Actions runs update_dashboard.py once a day, pulling fresh values from BGeometrics' free API tier (8 requests, its full hourly allowance) plus Alternative.me for sentiment, then rebuilds this page and publishes it to your GitHub Pages URL. Nothing to run manually. Thresholds in the script are illustrative starting points — tune them in update_dashboard.py as your own conviction develops.
